# AI • Create • Inspire — Portfolio Website

A responsive, static portfolio website for showcasing AI-assisted projects, prompt engineering, teaching, Lovable website-building training, and Tinkercad 3D design education.

## Files
- `index.html` — page content and metadata
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year, subtle reveal effects

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL@example.com` and replace it with your preferred email address.
3. Personalize the About section with your name and verified qualifications/experience.
4. Check each project description and update it if a project’s actual functionality differs.
5. Preview `index.html` in a browser.

## Publish for free with GitHub Pages
1. Sign in at https://github.com/ and create a new public repository (for example, `ai-portfolio`).
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. Open repository **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for the published URL to appear in Pages settings. It will usually look like `https://YOUR-USERNAME.github.io/ai-portfolio/`.

Alternative: drag the folder into a static-site host such as Cloudflare Pages if using its direct upload workflow.

## Notes
- This site does not need a database or backend.
- The “View all projects” buttons point to your existing project hub: https://project-link-landing.lovable.app/
- The email button uses a `mailto:` link; it opens the visitor’s email application and does not submit a web form.
- Decorative project visuals are CSS illustrations, not screenshots of actual apps. Replace them with genuine screenshots for the strongest application portfolio.
- The page makes no claims of employment by or endorsement from DataAnnotation.
